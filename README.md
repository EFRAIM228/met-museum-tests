# Автотесты для API Музея Метрополитен

Набор автоматизированных тестов для проверки функциональности API Метрополитен (https://metmuseum.github.io).

## Статус

- Все тесты проходят: 6 passed
- Валидация ответов через Pydantic
- Обработка изменений API (переход с v1 на v1.1 для поиска)

## Технологии

- Python 3.12
- pytest
- requests
- pydantic

## Запуск

1. Активировать виртуальное окружение:
   venv\Scripts\activate
2. Установить зависимости:
   pip install -r requirements.txt
3. Запустить тесты:
   pytest -v

## Особенности реализации

- Для эндпоинта /objects/{id} используется версия API v1.
- Для поиска (/search) используется актуальная версия v1.1, так как v1/search был отключён.
- Модели Pydantic учитывают реальные поля ответов API: некоторые поля сделаны Optional, чтобы корректно обрабатывать отсутствие данных.

## Структура проекта

- models.py — Pydantic-модели для валидации ответов API
- conftest.py — фикстуры pytest и настройка логирования
- test_met_api.py — тесты API
- requirements.txt — список зависимостей
- logs/test_run.log — файл с логами запросов и ответов
